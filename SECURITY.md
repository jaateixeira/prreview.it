# Security policy

Previewit handles sensitive review data and relies on reviewer anonymity, so we take reports seriously.

**Please report vulnerabilities privately** using GitHub's "Report a vulnerability" button (Security → Advisories) on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and the impact. Identity leaks (a reviewer or author being identifiable when the policy says they should not be) count as security issues.

We aim to acknowledge reports within 5 working days. The project is pre-1.0; only the `main` branch is supported.
